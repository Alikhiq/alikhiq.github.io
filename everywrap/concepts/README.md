# EveryWrap hero concepts

Four hero directions for the everywrap.com redesign, rendered on kie.ai (nano-banana-pro, 2K, 16:9) with real EveryWrap work photos as references. These are design mockups, not photographs of finished jobs.

| File | Concept | Role in the site |
|---|---|---|
| `everywrap-hero-A-spotlight.jpg` | Spotlight | Default personal hero: satin black car on a turntable, finish swatches, service dial |
| `everywrap-hero-B-peel.jpg` | The Peel | Vinyl wrap state and "Try it on my car": drag the seam to wrap the car |
| `everywrap-hero-C-nightdrive.jpg` | Night Drive | Window tint state: tint level selector on a night street |
| `everywrap-hero-D-dual.jpg` | Two Worlds | Personal / Commercial switch: dark luxury theme vs bright fleet theme |

`v1/` holds the first pass. `prompts/` holds the exact prompts for both passes.

Shared UI across all four: `EVERYWRAP` wordmark, `PERSONAL | COMMERCIAL` toggle, one primary button "Get my price in 60 sec", and an assistant input "Tell me your car and what you want…".
