## Rejected / not usable (license or fit)
- three.js `ferrari.glb` (above): license unverifiable, source disabled, OEM trademark.
- Sloyd sedan (https://www.sloyd.ai ... a-red-mid-sized-four-door-sedan-1990s-to-early-2000s-04dtwkw5, CC BY 4.0): downloaded and inspected, 39k tris, ONE mesh and NO materials (`Sedan`) so paint/glass cannot be separated. Rejected technically, license itself fine.
- GitHub HoanghoDev/3dmodel Porsche 911 GLB: license link is CC BY-SA 4.0 (share-alike, risky for a commercial site). Not downloaded.
- Other Sketchfab Ferrari 458 / Aventador etc. listings, CGTrader, TurboSquid, RenderCrate, The Pixel Lab free items: royalty-free custom licenses, no-redistribution, or unclear. Not used. Sketchfab downloads need login anyway.
- Kenney kenney.nl direct zip: 403 from sandbox; used the identical OpenGameArt copy (CC0).

## Traps
- CarConcept README says the Khronos and 3D Commerce logos are "Khronos Trademark or Logo" (LicenseRef-LegalMark-Khronos): non-copyrightable marks but trademark-marked. Remove/replace those decals before shipping (they are in the `Hardware` / steering emblem / license textures). Cesium logo on the milk truck likewise.
- CC BY 4.0 requires attribution: put it on a credits/footer page.
- The current site car is a Lamborghini Aventador (trademark) with CC BY 3.0 provenance not independently verified.
- Kenney GLBs reference an external Textures/colormap.png; I embedded it. Do not copy the originals.
