# Fonts & icons (not downloaded)
All on Google Fonts, SIL OFL 1.1. Avoid Inter / Space Grotesk. Current site: Newsreader + Instrument Sans.
1. **Fraunces** (soft-serif display, variable w/ optical size; use light weight, wonk off) + **Hanken Grotesk** (text) — warm editorial luxury.
2. **Bodoni Moda** (high-contrast didone display; fashion/watch feel) + **Manrope** (clean geometric text) — high-end showroom look; use Bodoni at large sizes only.
3. **Syne** (wide, characterful display, extra-bold for headlines) + **DM Sans** (text) — modern performance/automotive edge; or for a more technical feel pair **Unbounded**/**Michroma** display + **Figtree** text.
Optional mono for spec labels: **JetBrains Mono** / **IBM Plex Mono** (OFL).
Icons: **Lucide** (ISC licence, MIT-compatible; `lucide-static` SVGs or npm `lucide`) — consistent stroke icons, tree-shakeable. Alternative: **Phosphor Icons** (MIT) for more weights/duotone; Tabler Icons (MIT).
